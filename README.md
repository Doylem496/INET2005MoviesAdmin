This project is a web app meant to emulate Rotten Tomatoes. We will be managing CRUD operations with a database for admins of the site, including movie titles, ratings, 
release years, genres, runtimes etc.
It will be built with a mix of Razor and C# in a ASP.NET framework.
The front end will be done in react foe better presentation.
Responsive design should be kept in mind for phone and tablet view.
